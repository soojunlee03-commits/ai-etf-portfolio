# 학생 빠른 시작

**로그인 → 초기 자산배분 → 100% 확인 → 최종 제출 → 성과 확인 → 리밸런싱 → 이력 확인**

1. 교수자가 알려준 URL에서 **아이디**, **비밀번호**를 입력하고 **로그인**하세요. 계정이 없으면 **처음 오셨나요? 학생 회원가입**에서 아이디·공개 닉네임·8자 이상 비밀번호를 직접 정하고 수업을 선택해 가입하세요. 교수자가 발급한 임시 비밀번호로 로그인한 경우에만 **비밀번호 변경**을 완료합니다.
2. **학기 / 수업**을 확인하고 **내 포트폴리오**의 “지금 해야 할 일”을 읽으세요.
3. 다섯 ETF 비중을 입력하세요. 연습 예: SPY 30, IEF 25, GLD 15, VNQ 15, SGOV 15.
4. **현재 합계 100%**, **남은 비중 0%**, **제출 가능**을 확인하세요. 제출 전 표와 적용일을 검토합니다.
5. 확인란을 체크하고 **초기 자산배분 최종 제출**을 누르세요. 제출 완료 후에는 수정할 수 없습니다.
6. **성과**에서 기준일, NAV, 달러·원화 수익률을 확인하세요. NAV 105는 시작 대비 +5%입니다.
7. **리밸런싱**이 열리면 새 비중과 **20자 이상 사유**를 입력하고 확인 후 **리밸런싱 최종 제출**을 누르세요.
8. **포트폴리오 이력**에서 기록을 확인하고 **로그아웃**하세요. 오류가 계속되면 비밀번호 없이 학기·메뉴·발생 시각을 교수자에게 전달하세요.

전체 설명은 앱의 **사용가이드** 또는 Student_Manual_KO.md를 참고하세요. 실제 투자나 주문이 아닌 교육용 모의투자입니다.
