# 관리자 빠른 시작

**로그인 → 학기 설정 → 학생 등록 → 제출 확인 → 리밸런싱 설정 → 성과·순위 확인 → 백업·내보내기**

1. 앱 URL에서 관리자 계정으로 **로그인**합니다. 임시 비밀번호라면 새 비밀번호로 변경합니다.
2. **학기 / 일정**에서 학기명, 시작일, 종료일, 초기 마감일·시각을 넣습니다. 확인 후 **새 학기 생성**을 누릅니다. 마감은 시작일보다 앞서야 합니다.
3. 사이드바에서 새 학기를 선택하고 확인란을 체크한 뒤 **운영 학기로 설정**을 누릅니다.
4. 학생에게 앱 URL과 학기 이름을 전달하면 학생이 로그인 화면에서 직접 회원가입하고 수업을 선택할 수 있습니다. 직접 가입한 학생은 비밀번호를 재변경하지 않습니다. 교수자가 계정을 대신 만드는 경우에는 **학생 관리**에서 아이디, 공개 닉네임, 학생별 임시 비밀번호를 넣고 **학생 등록**을 누릅니다. 기존 학생은 **선택 학기에 수강 등록**을 사용합니다.
5. 학생에게 URL과 개인 계정을 전달하고 **운영 현황**에서 초기 미제출을 확인합니다.
6. **학기 / 일정**에서 회차 이름, 시작·마감·적용일을 확인하여 **일정 추가**를 누릅니다. 기본 간격은 14일입니다.
7. **시장 데이터 → 무료 시장 데이터 가져오기**로 완료 거래일까지 저장합니다. **데이터 상태** 경고를 해결한 뒤 **공식 성과 확정**을 누릅니다.
8. **학기 / 일정 → 순위표 공개 (OPEN)** 및 확인란을 체크하고 **운영 설정 저장**을 누릅니다.
9. **내보내기 / 백업**에서 학기 ZIP과 완전 DB 백업을 다운로드합니다. 학기 종료 후 보관하고 다음 학기를 생성합니다.

가격이나 배분을 정정하면 공식 성과를 다시 확정해야 합니다. JSON·CSV는 완전 DB 복구를 대신하지 않습니다. 복구·오류 대응은 [관리자 상세 설명서](Admin_Manual_KO.md)를 읽으세요.

학기를 삭제하려면 **학기 / 일정 → 학기 전체 삭제**에서 이름을 입력하고 확인 후 삭제합니다. 일반 목록에서 제거되며 기존 기록은 **삭제한 학기 · 휴지통**에서 복원할 수 있습니다.

**학기 / 일정 → 학기 설정 요약**에서 선택한 학기의 저장된 시작·종료일, 초기 제출 마감, 운영 학기 지정, 공개·보관 상태, 공식 성과, 학생·제출 수와 리밸런싱 일정을 확인합니다. 새 학기 입력은 별도의 **새 학기 만들기**를 펼쳐 사용합니다.

**학생 성과 / 제출 내역**에서 학생별 ETF 목표 비중, 최근 제출일·적용일·사유를 확인합니다. 학생을 선택하면 전체 제출 이력과 성과 차트를 조회할 수 있습니다. 시장 가격이 없어도 저장된 제출 내용은 표시되며, 제출 전 작성 중인 내용은 서버에 저장되지 않아 조회할 수 없습니다.

최신 시장 자료가 늦어도 시작일부터 마지막 저장일까지 누락 없이 검증되면 관리자에게 해당 기준일의 참고 성과를 표시합니다. 기간 중 가격 누락·데이터 오류가 있으면 성과를 숨기며, 공식 순위는 기존 데이터 점검과 확정 절차를 통과해야 합니다.
